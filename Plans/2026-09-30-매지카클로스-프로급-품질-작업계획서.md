## 조사로 확정한 사실 (근거)

1. **깊이 커브가 품질의 핵심** — MC2 `[C]` 파라미터는 베이스라인 깊이
   (0.0=고정단→1.0=끝단)에 따라 값을 달리한다. 공식 스커트 프리셋도
   distanceStiffness 1.0→0.5 등 커브를 사용(복사본 JSON으로 확인).
   `CurveSerializeData.SetValue(value, curveStart, curveEnd, useCurve)`로
   양끝단을 지정 가능. (magicasoft.jp/mc2_baseline, mc2_parameter_setup)

2. **BoneCloth SequentialLoopMesh** — `connectionMode=2`는 rootBones를
   **등록 순서대로** 연결해 처음과 끝을 루프로 잇는 면을 형성
   (스커트·원피스·망토용). `AutomaticMesh(=1)`는 루트를 최근접점 순으로
   자동 정렬하지만 처음-끝 폐합은 하지 않는다(RenderSetupData.cs:63-80,
   VirtualMeshInputOutput.cs:529-554). 일본 TA 실무 기준 애니메이션 강도
   중간까지는 이 모드로 충분하며 PC 부하가 MeshCloth보다 현저히 낮다.
   (note.com/logic_magic/n/n6f7fd6be02c6)

3. **애니메이션 포즈가 백스톱의 전제** — 백스톱은 프록시 메시의
   "애니메이션 포즈" 기준으로만 작동. 스커트 정점이 다리 본에 스키닝
   되지 않은 모델에서는 `customSkinningSetting`으로 프록시를 지정 본에
   자동 스키닝해야 한다(공식 "대체 기능", 수동 웨이트보다 정밀도 하위).
   BoneCloth 경로는 정점=본이라 이 전제가 구조적으로 성립한다.
   (mc2_magicacloth_customskinning)

4. **애니메이션 키 제어 프로퍼티 7종** — `MagicaCloth`는
   `blendWeightProperty`, `animationPoseRatioProperty`, `gravityProperty`,
   `dampingProperty`, `worldInertiaProperty`, `localInertiaProperty`,
   `windInfluenceProperty`를 애니메이션에서 변경 시 자동
   `SetParameterChange()` 호출(MagicaClothAnimationProperty.cs).
   BlendWeight는 "의자에 앉는 컷만 아티스트 애니메이션으로 전환"이 공식 용례.

5. **배포 파괴 지점** — 빌드에서 Burst 비활성 시 수십 배 저하 실보고,
   Managed Stripping `High`는 Burst를 실제 파괴(Unity 버그 신고 이력).
   v2.3.x부터 `MAGICACLOTH2`/`AlwaysLinkAssembly` 자동 주입으로 스크리핑
   누락은 방지됨(우리 버전 v2.18.1 해당). Burst AOT 설정 파일은 현재
   프로젝트에 없음(기본값 상태 — 빌드 전 명시 확인 필요).

6. **기존 구현이 이미 커버** — `updateMode=AnimatorLinkage`(스커트 빌더
   :492), 관성 속도제한·스무딩·텔레포트, 앞머리/스커트 백스톱, 컬링,
   PlayerLoop 가드(공식도 v2.12.0에 동일 기능 추가 — 방향 일치 확인),
   프리셋 베이스라인.

7. **QA 인프라 재사용 가능** — `PhysicsValidationProbe`(침투 계측),
   `PhysicsValidationSequence`(자세 시퀀스), `NativeHumanoidAnimationPlayer`/
   `HumanoidMotionPlaybackController`/`NativeHumanoidPlaybackBaselineRunner`
   (VMD 재생), `sdata.ExportJson()`(파라미터 스냅샷 가능).

## 환경 규칙 (전 구간 적용)

1. 작업 단위 = 이 워크트리 + 이 브랜치. 다른 워크트리·작업선 파일 불건드림.
2. Unity 에디터 = `Unity_Fbx2VMD-magica` 인스턴스에서만 검증.
3. 의미 단위 커밋 — 미추적 상태로 방치 금지.
4. 비대상 재확인: BoneSpring(가슴 전용·요청 제외), Self/Mutual Collision
   (베타·고부하·고속 얽힘), Edge 모드 전환(실측 문제 없음).
   Penetration 제약은 v2.18.1 미지원 → 업그레이드 시 별도 항목.
5. BoneCloth 신규 경로 도입 시 기존 MeshCloth 경로는 옵션으로 보존
   (롤백 경로 상시 확보).
