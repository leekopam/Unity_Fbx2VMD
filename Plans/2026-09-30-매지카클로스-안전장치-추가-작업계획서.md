# MC2 안전장치·품질 강화 작업계획서 (2026-09-30)

선행: `2026-09-30-매지카클로스-전용워크트리-작업계획서.md` (Phase 0–5 완료, PR #2 머지)
작업 위치: `Unity_Fbx2VMD-magica` 워크트리, `agent/magica-physics` 브랜치 (계획서 0-1의 격리 규칙 유지)

## 목표

조사로 확정한 실전 가치 항목을 전용 자동화에 추가한다.

## 환경 판정

- 설치 MC2: **v2.18.1** (`AboutMenu.MagicaClothVersion`)
- **Penetration 제약(Surface/Collider Penetration)은 이 버전에 없음** — 상위 버전 전용 기능.
  대체로 스커트 Backstop(MotionConstraint)을 적용하고, 정식 Penetration 자동 선택은
  MC2 업그레이드 시 별도 항목으로 처리.
- 기존 구현이 이미 커버: 헤어/스커트 관성 속도제한·스무딩·텔레포트 거리, 앞머리 백스톱,
  긴 체인 Edge 모드, 추출 스커트 Reduction.

## 항목

| # | 항목 | 방식 |
|---|------|------|
| 1 | 프리셋 베이스라인 | `Assets/Resources/PhysicsPresets/`에 공식 프리셋 JSON 복사 → `ClothPresetLibrary`가 `Resources.Load`+`ImportJson`으로 베이스라인 적용 후 기존 템플릿이 델타를 덮어씀. 프리셋 없으면 기존 수작업 경로로 폴백 |
| 2 | 컬링 옵션 | `cameraCullingMode`(기본 AnimatorLinkage)·`distanceCullingMeters`(기본 0=끔, 녹화 안전)을 생성 클로스 전체에 적용 |
| 3 | PlayerLoop 가드 | `MagicaManager.InitCustomGameLoop()` 주기적 재등록 — 다른 에셋의 PlayerLoop 덮어쓰기로 시뮬 정지 방지 |
| 4 | 빌드 실패 리포팅 | `OnBuildComplete` 구독 → 실패 시 경고+리포트에 기록 |
| 5 | 스커트 Backstop | MotionConstraint 백스톱을 스커트에 옵션 적용 — Penetration 대체 (체간 침입 차단) |
| 6 | 스커트 Reduction 배율 | 프록시 밀도를 인스펙터 배율로 조정 가능하게 |
| 7 | 스커트 teleportMode | 헤어와 동일하게 Keep 지정 (폭주 방지 일관성) |

비대상: BoneSpring(가슴 전용·요청 제외), Penetration 제약(버전 미지원), Self/Mutual Collision(베타·고부하), Edge 모드 전환(실측 문제 없음), Wind(용도 없음)
