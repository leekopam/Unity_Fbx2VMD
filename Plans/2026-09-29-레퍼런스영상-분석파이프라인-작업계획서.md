## 1. User goal

- Satisfaction MMD 영상을 하체·상체 보정과 머리카락·의상 물리 튜닝의 검증용 정답 데이터로 전환.
- 발 마커 없는 FBX의 접지 의도를 영상 접촉 라벨(은데이터)로 해소.
- 제약: 자동화 가능, 무료 도구만, 품질 우선, 수동 검수는 불확실 구간만.

## 3. 주요 발견 (계획에 영향)

1. **영상↔raw VMD 정합 확정** (최초 "불가"는 상관 구현 버그) — `vmd=video/2+1358`, inlier 56%.
   → 영상=VMD의 후처리본(사용자 확인과 일치). **보정 맵 경로 부활**:
     영상 라벨/궤적 − VMD 곡선 diff = 수작업 보정 정량화 가능.
   → satisfaction_2.fbx는 145초 별개 컷(영상 200s, VMD 207.7s). Unity 정합은 풀버전 FBX 또는 컷 구간 확인 필요.
2. 머리 피팅 주기(~0.1s)가 물리 스웨이보다 빠름 — 마스크 최하단 점의 가닥 전환 노이즈.
   후속: 무게중심 궤적 또는 정착구간 선별 강화.
3. 키포인트 샘플 사람 검수 미실시 — 시트는 산출됨.

## 4. 남은 작업 (2026-09-30 재편 — 목적별 매핑)

확정 사실: 영상↔VMD 정합 `vmd=video/2+1358` (골반 일치, 발 불일치=수작업 보정 신호).
satisfaction_2.fbx는 207.8초로 영상과 같은 클립 — Unity all-frames.csv(12468f@60) 존재.

### W1. 검수 게이트 (사람, 소규모)

- sheet_38s/113s.png 키포인트 육안 판정 (전신 ≥90%, 발 ≥85%)
- review_queue.csv 11구간 확인 → 접촉 라벨 확정/보정 → 정답 승격

### W2. 발 보정 맵 (목적2 핵심, 구현) — 완료

- 정합 프레임으로 영상 발목 궤적 − 소스 발 궤적 diff 산출
- 소스 발 궤적: Unity all-frames.csv의 source_foot(FBX 원본 궤적 = VMD와 동일 클립)
- 구간별 보정량 정량화: 높이·전후·측면 오프셋, 보정 유지시간, 보정 빈도
- 산출: correction_map.csv (프레임, 발, 오프셋 벡터, 유형 태그)

### W3. 접지 의도 피팅 (목적1, 구현) — 완료(음성 결과 기록)

- contact_intervals(영상 정답, VMD/Unity 프레임 변환 완료)를 은데이터로
- Unity 특징(발 높이/속도/전후 무게)로 임계 자동 피팅 → F1/정밀도/재현율
- 산출: intent_rules.json(임계+히스테리시스 파라미터) + 성능 지표
- 전제: W1 승격 완료

### W4. 자세 유지 diff (목적2 보조, 구현) — 완료(2D↔3D 근사 무의미 판정, 유효 경로 명기)

- W2 정합 기구 재사용 — 골반/척추/어깨 궤적 diff
- 하체 보정이 상체 자세를 당기는 구간 식별 → posture_diff.csv

### W5. 물리 정밀화 (목적3, 구현) — 완료(무게중심 추적)

- 끝점→마스크 무게중심 궤적 교체, 정착구간 선별 강화 → ζ, ω_n 재피팅
- HairTuning 매핑 대응표 초안, 스커트는 필요 시 SAM2 검토

### W6. UniVRM 전환 대응 (사전 설계, UniVRM 0.130.1 설치됨) — 완료(bone_map.json)

- MMD↔Humanoid 본 매핑표 1회 작성 (hips↔センター, leftFoot↔左足首 등)
- VRM SpringBone 메타데이터를 물리 체인 제1 소스로 (이름 추측 대체)
- 전환 직후 접지 기준 미세 변동 → 영상 라벨로 1회 재검증
- 산출 스키마는 CSV/JSON 유지 (E2E/외부 도구 소비)

### W7. 다른 곡 영상 적용 (확장)

- Movie/ 폴더 동류 영상 동일 파이프라인 적용 (GPU로 수 분/곡)
- 곡별 라벨 누적 → 검증 커버리지 확장

### 순서/의존

- W1: 언제든 가능, W3의 선행 게이트 (W2는 무관)
- W2 → W4 (정합 기구 재사용)

## 6. 수용 기준 (남은 작업)

- W1: PCK·F1 기준 통과 여부 기록, 라벨 승격/재검토 판정 — **사용자 대기**
- W2: 완료 — 21구간 중 19건 "후처리 추가 접촉" (소스FBX는 지면 접촉 자체가 없음 확인: src_y min≈7.6cm)
- W3: 완료 — 소스 특징 피팅 불가 확인(구간재현율 L0.18/R0.0) → 의도=영상 라벨 직접 사용 경로 확정
- W4: 완료 — 2D 화면 기울기↔3D roll 직접 대응 무의미 확인 → VMD Unity 재생 후 3D 직접 비교로 이관
- W5: 완료 — 무게중심 추적으로 주기 0.25~0.57s, ζ 0.016~0.185 산출 (관측치, 정밀도 보류)
- W6: 완료 — bone_map.json + VRM0.x API 한계 명기 (VRM1.0은 별도 패키지 필요)
- 각 산출물 manifest.json 포함 재현 가능
